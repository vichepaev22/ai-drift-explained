# AI / DRIFT — понятная интерактивная карта трендов ИИ

Русскоязычный статический лендинг-пояснение к исследованию **Drift Inspector**.

- Данные основной карты: **117 888** статей, **570 179** атомарных утверждений, **2018–2026**.
- Численные выводы (>10× агенты, 3,1× vision-language modeling, −97% parsing и −3,7…−4,4 п. п. классические NLP-задачи) относятся **только к отдельной выборке EMNLP 2020–2025**. Они не утверждаются для всей общей карты.
- Интерактивный навигатор тем — редакционная адаптация; его карточки не являются полной репликой библиотеки 570 тыс. утверждений.
- Продуктовые гипотезы отдельно помечены как интерпретация.

## Развёртывание

Сайт — один `index.html` без сборки, зависимостей JS и серверной части. GitHub Pages: **Deploy from a branch → main → / (root)**. Внешний шрифт Manrope загружается при наличии сети; без него используется системный шрифт. Картинка Telegram-превью расположена в `assets/share.png`.

## Правовой статус

Независимый информационный разбор. Не аффилирован с создателями Drift Inspector. Цифры и научные выводы приведены со ссылкой на оригинальные материалы. Исходный код этого сайта не копирует программу исследователей.
