# Атлас ИИ — русскоязычная интерактивная карта науки

Переработанная версия сайта с реальными данными [Drift Inspector](https://drift.autumnfleet.com/i/all-conf/), AIRI / Skoltech, EMNLP 2026.

Содержит шесть разделов: обзор, 3D-карта научных утверждений (Three.js), 98 тем на русском языке, Topic Trends (рост/спад и траектории по годам), Compare (сопоставление конференций/периодов по доле статей или утверждений), методика и первоисточники.

Числа в исходных данных: 117 888 статей, 570 179 утверждений, 98 тем за 2018–2026 гг. После успешной сборки сайт позволяет отображать до 570 179 точек, фильтровать их по годам и темам и по нажатию получать оригинальные научные утверждения и ссылки на публикации. Стандартный режим отрисовывает каждую третью точку ради быстродействия; режим «Все точки» показывает полный набор.

## Данные

Наборы не создаются искусственно. GitHub Actions во время деплоя загружает неизменяемый набор из публичного источника `https://drift.autumnfleet.com/d/all-conf/8284613a3ebc/` и публикует его вместе с сайтом. При недоступности источника сборка останавливается и не публикует ложные цифры. `topics.json`, `members.json`, `map.json`, `papers.json`, `manifest.json`, `derived/aggregates.json`, 165 шардов claims и 269 шардов authors. При просмотре карты сначала грузятся только map/members/papers, а конкретное утверждение читается из шарда по запросу.

Тема исследования ≠ рыночный спрос. Доли не складываются до 100%, так как статья может относиться к нескольким темам. Наименования и интерфейс переведены на русский, исходные научные формулировки сохранены на английском для точности.

## Публикация

GitHub Pages использует `.github/workflows/pages.yml` с `workflow_dispatch` и `push:main`. На первом деплое загрузка полного набора может занять несколько минут. Проект не требует API-ключей или платного сервера.
